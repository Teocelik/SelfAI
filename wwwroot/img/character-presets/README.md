# Karakter Placeholder Görselleri (Mock Data)

Bu klasör F.5c modal UI testi için 6 placeholder karakter görseli içerir.
F.6'da gerçek API entegrasyonu yapıldığında, karakterler kullanıcının
oluşturduğu gerçek karakterlerden gelecek.

Mock isimler:
- char-01.jpg (Mira)
- char-02.jpg (Mariana)
- char-03.jpg (Mira)
- char-04.jpg (Marco)
- char-05.jpg (Marcus)
- char-06.jpg (Mateo)

Görsel önerileri (kullanıcı eklemeli):
- Portrait shot, head-shoulders
- Sade arka plan
- Square veya near-square aspect ratio
- 256x256 - 512x512 boyutunda
- JPG / PNG / WebP, 100-500KB

Görseller yoksa kart placeholder ikon (fa-user) gösterir.
